## miras_framework.md
The MIRAS (Memory, Integration, Retention, and Attentional Structure) framework is a theoretical and unifying architectural paradigm introduced in late 2025 to formalize the design of sequence models as associative memory systems. While previous research often treated memory and attention as distinct components, MIRAS posits that all effective sequence models—including Transformers, RNNs, and State Space Models (SSMs)—can be understood through four fundamental design pillars: Memory Architecture, Attentional Bias, Retention Gate, and Optimization Rule.

The MIRAS framework provides a rigorous mathematical structure for designing "attention-free" architectures. The first pillar, Memory Architecture, defines the physical or mathematical structure used to store information, ranging from simple vectors to complex, multi-layer perceptrons (MLPs) capable of high-dimensional associative storage. The second pillar, Attentional Bias, dictates how the model selects which parts of the memory to retrieve, effectively replacing the traditional softmax attention mechanism with a more efficient, learned retrieval process.

The third pillar, the Retention Gate, is critical for managing the "forgetting" problem. It determines the rate at which information is decayed or preserved within the memory structure, allowing the model to prioritize recent context while maintaining long-term dependencies. Finally, the Optimization Rule defines how the memory is updated—either through standard backpropagation during pre-training or through gradient-based updates during inference (test-time training). By standardizing these components, MIRAS allows researchers to systematically iterate on new architectures like Moneta and Yaad, which optimize for specific memory-to-compute ratios. This framework is essential for the next generation of AI, moving away from the "brute-force" attention of Transformers toward more elegant, biologically inspired, and computationally efficient associative systems.
